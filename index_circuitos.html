📘 Teoría · ¿de dónde sale la ecuación?

Según la segunda ley de Kirchhoff, el voltaje aplicado E(t) a un circuito cerrado es igual a la suma de las caídas de voltaje.

Inductor: L·di/dt = L·d²q/dt² · Resistor: iR = R·dq/dt · Capacitor: q/C

Como i = dq/dt, al sumar las tres caídas se obtiene:

L·d²q/dt² + R·dq/dt + (1/C)·q = E(t)

Ecuación característica: L·m² + R·m + 1/C = 0. Según el discriminante R² − 4L/C:

• > 0: raíces reales distintas → sobreamortiguado.
• = 0: raíz real doble → críticamente amortiguado.
• < 0: raíces complejas → subamortiguado (oscila y decae).
• R = 0: raíces imaginarias puras → oscilación sin amortiguamiento.

Numéricamente se reescribe como sistema de primer orden: q′ = i, i′ = (E(t) − R·i − q/C)/L, y se integra con Runge-Kutta de orden 4.
